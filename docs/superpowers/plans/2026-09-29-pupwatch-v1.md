# PupWatch v1 Implementation Plan

> Executed inline (user preference: no reviewer agents). Steps use checkbox syntax.

**Goal:** Detect the dog on the Tapo C200, record a clip per visit, browse clips, and a live
page with talk + PTZ — per `docs/superpowers/specs/2026-09-29-pupwatch-v1-design.md`.

**Architecture:** go2rtc owns the camera; Phoenix/Ash app reads its RTSP restream with ffmpeg
Ports, runs YOLOX-nano through Evision DNN, records with ffmpeg `-c copy`, persists via
AshSqlite, relays WebRTC SDP to go2rtc, drives PTZ via ONVIF SOAP.

**Tech Stack:** Elixir 1.18 / OTP 27, Phoenix 1.8 LiveView, Ash 3 + AshSqlite + AshPhoenix,
Evision 0.2 (precompiled NIF), ffmpeg, go2rtc, NixOS (`mixRelease`).

**Dev loop:** code on squirtle in `~/projects/pupwatch`; `scripts/snorlax.sh <cmd>` rsyncs to
`snorlax:/mnt/main/projects/pupwatch` and runs `<cmd>` inside a `nix shell` with
elixir/ffmpeg/git/sqlite (snorlax = x86 target, has the camera on its LAN, 16 cores).
